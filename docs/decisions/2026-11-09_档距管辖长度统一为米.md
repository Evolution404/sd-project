# 档距管辖长度统一为米（2026-11-09）

## 用户裁决

档距的输电中心管辖长度在用户输入、展示、表格筛选、历史审计、Excel模板、导入、导出及业务报表中一律使用**米**，最多保留 **3 位小数**。用户不接触“毫米数”的编辑字段。

## 技术口径

- 正式字段显示名为“输电中心管辖长度（米）”，业务控件类型 length_m。
- Vue 公共 FieldControl 对 length_m 显示内部长度除以1000，保存时按3位小数乘1000，写入整数。
- SQLite 保留 line_spans 和 line_span_history 的 transmission_center_length_mm 整数毫米定点存储，不改变原有物理字段与历史数据，也无需迁移。
- NULL 表示未知，0 表示明确无管辖长度，两者含义不同。
- 共享列表、详情和 BusinessHistory 正式历史统一显示米；Repository 的搜索/筛选也按米的3位小数匹配。
- Excel原来已经使用米，本轮明确模板使用说明与显示单位，不重复换算。整数毫米只是数据库内部精确表达，并不是业务口径。

## 验收方式

- tests/api/span-length-metres.test.mjs 验证元数据、历史定点数、米制搜索和筛选、NULL/0、Excel表头及双向换算。
- tests/e2e/span-metres-browser.mjs 验证真实鼠标浏览器列表/详情/编辑、历史和列筛选。输入130.125米，内部应保存130125。
- 全套 check、check:schema、test:browser；Windows原生环境仍须实机验收。
