# P10 使用指引与独立训练：实施验收

## 已实施内容
- P10.0：12个业务模块与Excel专题的帮助注册及82个已登记语义动作，说明前提、正式结果、风险、角色和适用状态；通过 scripts/generate-guide-inventory.mjs 生成帮助清单。
- P10.1至P10.2：单例GuideHost、Element Plus ElTour、页面5步骤短导览、全部12个模块介绍、搜索、Excel专题、L01～L12阅读课程、本机按账号隔离阅读进度、路由变化退出和目标丢失时文字退路。
- P10.3：提供单用户独立训练实例。scripts/training/instance.mjs 可创建/启动/列出/确认重置一个实例，默认127.0.0.1:8791，独立 DATA_DIR、随机实例ID和真实管理员口令。训练身份仅由服务器环境与实例标记严格确认，不能从URL、请求头或本机阅读记录伪造。
- 已认证、只读 GET /api/training/checkpoints 的L01至L12状态全部来自训练库实际正式业务数据；涵盖基础配置、设备、操作计价、多位置需求与确认、项目承接、正式批准与变更、实际费用、两份独立已审核结算、费用核对结项、Excel预检/提交、真实403与审计。单纯点击课程“下一步”从不会形成实操通过。
- P10.4：已集成Windows独立训练启动和实例列表命令、离线静态教程及打包资源检查；正式、演示ZIP中都包含教程与操作清单。

## 关键安全约束
- 正式环境指引只显示说明/可控导览，不自动提交、审批、撤回、结算或删除；课程实际操作沿用原服务端权限。
- 训练数据与正式及演示隔离；只有匹配的训练实例目录才打开完成状态。重置必须输入完整实例ID并且服务器未运行。
- 课程阅读状态与服务端实操通过分开，只有实际数据核验才能将课程标记通过。
- 82项注册说明并非所有动态行级按钮100%覆盖的证明；实际跨角色课程完成取决于训练实例的真实业务记录，不能把教程已声明当成用户实操已完成。

## 使用
Mac开发环境设置 SD_TRAINING_ADMIN_PASSWORD 后执行 node scripts/training/instance.mjs create，记录实例ID，再执行 node scripts/training/instance.mjs start --id=实例ID --port=8791。浏览器访问 http://127.0.0.1:8791。结束前停止训练服务，再执行 node scripts/training/instance.mjs reset --id=实例ID --confirm=实例ID。Windows ZIP中提供“启动训练环境.cmd”与“训练实例列表.cmd”。培训和演示密码只交付获授权用户。
