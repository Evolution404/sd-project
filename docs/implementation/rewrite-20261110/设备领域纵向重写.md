# 设备领域纵向重写

2026-11-10，承接树形专项提交002d95b，继续原P0至P9全面重写。当前阶段聚焦设备领域与电压等级的前后端边界。

## 实际替换

设备业务从Catalog应用服务迁至严格TypeScript的 `server/modules/equipment/service.ts`。设备Repository限定线路、物理杆塔、逻辑杆塔、档距及电压等级，公开当前事实、集合查询、创建、正式修订、历史和关联回路等业务方法。应用服务不接触SQL或任意表写入。

设备HTTP处理由独立模块承担请求验证、列表参数、身份上下文、权限和幂等入口。原Catalog设备调用直接进入同一个设备用例，在线、Excel、其他领域引用和测试夹具复用该实现。原设备写入、整基更换和逐行显示关联实现已从Catalog服务删除。

设备内部身份由服务端生成。同线路杆号重复检查、显式共塔、普通创建独立实物、正式版本、完整设备历史、停退运约束、已删除对象历史更正、整基更换事务继续生效。电压名称更正保留先审计后修订的严格顺序及乐观版本，代码身份不变。关联实物创建后其他字段失败会完整回滚。

审计追加集中在类型化Audit Repository和平台Audit服务，Catalog及设备复用同一追加实现。

## 集合查询

设备分页保留数据库白名单筛选、排序和分页。显示关联只读取当前页身份，对所需物理塔一次集合读取全部真实回路。常见逻辑杆塔分页无按节点增加的查询，1条和200条页均固定4次读取，完整列表固定2次读取。物理塔页固定4次读取，保留全部关联回路及当前有效回路数。

## 前端

输电设备台账改为独立EquipmentPage、EquipmentEditor、EquipmentReplacementDialog及列定义。电压等级由同一领域页面在基础数据原页签展示。设备和电压专属代码从旧CatalogPage移除，设备台账不再加载作业标准及计价编辑逻辑。

设备页面保留四种分类、列表URL状态、30条分页、查询、双向排序、列筛选、持久化列偏好、批量Excel、业务详情模态框、历史及授权CRUD。详情使用服务端正式显示关联，一次详情请求取得展示信息。物理塔主列表以现场铭牌、塔型及实际关联等业务信息展示。

编辑器保留最少录入、同塔关系明确选择、独立实物属性按需展开、主支线和档距端点联动、日期及定点单位控件、字段错误和草稿保护。整基更换弹窗具有加载、失败重试、待核对回路、明确确认及取消草稿保护。

BusinessTable增加行类型参数及类型化slot，保留一套表格实现。未知动态字段由通用cell value承担，各领域可以直接使用稳定的强类型row。已有树、财务页面按该类型契约调整，交互能力保留。
