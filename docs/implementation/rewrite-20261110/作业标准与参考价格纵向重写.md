## 实现与职责

- 作业对象及操作类型：`server/modules/work-standards/service.ts` 与 `server/database/repositories/work-standards.ts`；正式版本、固定作业对象和单位、位置范围、模板、附加字段与计价特征声明。
- 价格特征：`server/modules/pricing/factors.ts` 与 `server/database/repositories/price-factors.ts`；只允许额外现场枚举或整数因素，沿用单位正式版本。
- 价格规则：`server/modules/pricing/rules.ts` 与 `server/database/repositories/price-rules.ts`；八种模型、三作用域、重叠提示、明确版本采用及只读试算。
- 正式报价：`server/modules/pricing/service.ts` 与 `server/database/repositories/pricing.ts`；缺价说明、选价依据、预览指纹与不可变历史。
- 前端独立 `WorkStandardsPage`、`PricingPage` 与专用编辑器，操作类型四分区、价格规则三分区；保留BusinessTable、URL状态、模态详情和历史。旧计价及标准验证MJS移除，Catalog跨领域调用仅委派同一正式用例。
