# 架构与模块

## 运行链

`npm run build` 分别构建服务端和前端，分别输出dist/server与dist/web。`npm start` 执行dist/server/main.js，bootstrap组合领域服务，HTTP按资源注册路由。SQLite结构、连接、保存点、Repository及查询仅在database模块。

HTTP承担套接字/IP、登录会话、正文与幂等上下文、静态资源和错误转换。各领域http文件只将请求交给相应应用用例。领域纯计价、特征校验、定点数和错误不依赖驱动。

## 类型与剩余边界

已转TS的服务端代码采用严格检查，无显式any和忽略指令。保留的应用mjs由编译器输出后运行，仍需补齐各自正式请求/响应DTO和领域Repository。前端动态目录表单仍使用Row，尚未达到全业务类型收口要求。架构门禁扫描当前依赖图和数据库边界，持续补齐应用服务的类型后才能移除allowJs。

## 发布

Windows包运行dist/server/main.js，包含Node24、dist/web、dist/server、生产依赖、管理脚本和Schema。Manifest分别记录服务端源文件和编译文件SHA256。解压根data独立保留。宿主验证不能代替Windows实机CMD、PowerShell、防火墙及锁文件验证。
