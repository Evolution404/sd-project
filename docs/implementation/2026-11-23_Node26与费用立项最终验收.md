## 二、迁移与缺陷修复

1. 发布编排、ZIP 构造、正式版与演示版解包验收一致使用 `requireNode26`，Windows 运行时默认采用当前宿主 `process.version`，且明确验证包内/包外版本一致；官方 `SHASUMS256.txt` 与二进制压缩包须匹配，未降低验收强度。
2. `BusinessTable.vue` 的列设置复选框在隐藏后关闭再打开时可能复用旧视觉勾选状态，继而再次隐藏相同列，并写出重复 `hidden` 键。现按稳定列键与有效勾选状态重新挂载复选框，`show` 使用集合去重，保留列设置自动保存与“恢复默认仅影响列布局”的行为。
3. 档距列测试误用包含判断禁止“杆号”，会错误拒绝合法的“起点杆号／终点杆号”。改为精确识别独立禁止列；同时显式测试起点杆号的隐藏、重新显示、排序及列偏好，并保留物理/逻辑/档距三类表格结构和零业务写入断言。
4. 历史业务规则保持不变：项目整体承接整条需求，正式批准版本冻结；结算进度按当前生效批准预算和每张单据当前生效的已批准金额计算；草稿/待审/退回期间旧批准金额仍计入，结项冻结。
