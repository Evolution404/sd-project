# 全系统操作与项目结算改造

基线为 `eb5b961` 的 Schema113 重构分支。受控验收沿用隔离数据目录，标黄项目表的预算单位为万元，原表缺少的分项和变更按此前确认的模拟口径录入。

## 列表和办理操作清单

列表工具栏把搜索、列筛选及已删除开关放到左侧，把刷新、列设置和新增放到右侧。专业需求及子项目勾选后在同一位置展示选中数及批量操作。恢复默认列只恢复偏好，保留分页、查询、排序及勾选。表中的名称、编号、日志路径用于打开原记录，独立办理保留原列表上下文。

| 主入口 | 操作位置与对象 | 权限与前置条件 | 执行结果及失败恢复 |
|---|---|---|---|
| 工作台 | 待办事项按角色显示记录，点具体记录继续 | 确认需求、立项、变更、结算各按授予权限。立项核对关联需求和预计解决时间 | 显示待办数量及补正事项，查询失败时可刷新工作台 |
| 专业需求 | 工具栏新增、Excel、勾选后确认或关联。问题描述打开详情 | 确认权限、编辑权限、需求状态和关联版本决定可办范围 | 预检列出暂不可办原因。保留未处理勾选。表单错误定位，冲突保留草稿 |
| 子项目管理 | 工具栏新增、导出、批量入库。名称打开项目详情，概览进入办理 | 入库、批准、变更和结项各有权限，批准范围、日期与结算状态独立校验 | 批量预检可从全部项目发起。结项拦截列出具体结算单，可进入财务处理 |
| 年度框架 | 名称打开资金档案。详情编辑、看历史、删除，进入关联项目或财务 | 编辑者维护，管理员删除并核对引用与版本 | 删除影响列出关联项目和执行协议。资金概览包含按金额加权的进度 |
| 执行协议 | 名称打开协议档案。详情编辑、看历史、删除，关联项目进入同一财务工作区 | 新关联须符合框架、有效期和状态。删除预检复核关联项目 | 保留已引用的协议及历史，汇总只计本协议关联项目 |
| 费用与结算 | 项目财务办理费用、科目、结算与核对。跨项目记录按身份进入同一工作区 | 编辑者编制与提交，审核者批准或退回。已结项冻结普通写入 | 复核展示申请、已生效金额及净变化。退回可原版重提或修订 |
| 输电设备台账 | 名称或位置编号打开详情。详情编辑、历史、更正、整基更换和删除 | 管理员维护，删除前核对关联线路、杆塔、档距及需求位置 | 保留设备及位置的引用历史。整基更换继续使用专门核对 |
| 物资管理 | 名称打开档案。编辑、删除和版本在详情 | 管理员维护。引用影响和版本写入前复核 | 删除停止新增选用，原快照及正式历史保留 |
| 作业标准 | 名称打开正式定义。新增和编辑在办理页，历史和删除在详情 | 管理员维护。操作类型保留四个页签及正式引用校验 | 校验失败定位对应页签，返回保留原列表和关联任务 |
| 参考价格 | 规则名称打开详情，编辑和复制使用办理页 | 管理员维护。保存自动预检并按正式版本写入 | 试算可独立查看。未通过校验保留草稿，历史报价仍采用原规则 |
| 基础数据 | 字典名称打开详情。组织根级新增独立，选中单位可新增直属下级 | 管理员维护。调整上级须核对源、目标和最新版本 | 目标改变后重新预览，迟到的预览不使确认恢复可用 |
| 系统管理 | 账号和授权地址管理、操作审计按登记时间打开、访问日志按路径打开 | 管理员可维护访问策略。开启与关闭均有影响说明 | 日志查询应用输入，刷新和下载采用已应用条件，读失败保留可重试入口 |

## 结算合同

- 按项目总额为默认方式。填写大于零的金额可保存草稿，批准版本从项目上下文带入并可选用有效历史。
- 按子费用使用项目有效末级科目，明细合计形成唯一整单金额。两种单据可在同项目分期使用，单据内只能选择一种方式。
- 需求新增解决量独立选填，按当次所选的批准范围和冻结精度校验。总额计入项目，费用树只计明确归入科目的有效明细。
- 正式版本记录结算方式、本次金额、采用批准与资金版本。修订送审和退回保留先前批准金额，批准时以新版替换原单生效金额。
- 结算进度采用累计生效已批准结算 / 累计核定实际费用。缺基数显示已结金额和待核定提示，超结算显示金额差额。资金组合只用正费用基数项目做金额加权，另列缺基数项目数量。
- Excel 维护导出与业务报表复用当前列表查询，勾选导出只处理显式身份。维护文件缺失明细保持旧记录，明确删除才能移除明细。结项冻结同口径摘要并检查未提交、待审核、退回待处理。

## 隔离验收

- 现有浏览器门禁 60 个脚本全部覆盖，入口迁移后按失败项补测。专项通过列恢复保持查询和勾选、按状态和列条件导出、组织迟到预览保护、结项前费用与结算检查，以及四角色业务办理。
- 两个标黄项目覆盖三期总额和混合结算。通过需求修订、正式项目变更、退回后原版重提、修订批准、差额结项以及重启核对。详细证据位于 `test-results/schema113/two-source-projects/last-run.json`。
- 接口、领域、Excel 与界面合约合计 252 项，数据库业务规则合计 477 项，性能门禁 6 项。Windows 实机验收按用户安排暂缓。
