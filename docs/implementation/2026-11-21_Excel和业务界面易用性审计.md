# Excel 和业务界面易用性审计

审计版本为 `6351587`。在本机浏览器打开了十二个主入口，重点实际操作了需求、设备台账、项目财务和日志的下载、上传、校验与返回。下载后核对了 Excel 的表头、工作表顺序、错误内容和实际导出范围。采用隔离演示记录，本轮上传验证到校验阶段。

## Excel 模板与导入流程

- **用任务命名。** 日常入口显示「导入 Excel」和「导出 Excel」。批量改已有数据时点「用 Excel 批量修改」，在同一个流程下载已填好的表、上传、检查、保存。把「仅新增」「仅更新」「混合」作为有需要时才展开的限制，系统平时按文件中的记录身份区分新增与修改。
- **下载后就知道填哪里。** 专业需求的模板首列已有一条示例组号，作业位置仍要手工对应。把「需求清单」「作业位置」各放一行能配套理解的示例，在列旁说明何时填写。台账模板在「线路」和「档距」分类下载都以线路为第一个表，且要求阅读同一份四类台账说明。按入口定位首张填写表，将共塔、支线和独立实物说明放在对应列。结算默认展示本次金额，费用明细和需求解决量仅在用到时填写。
- **把技术指令换成业务语言。** 实际需求模板包含杆塔与结算说明，设备台账模板也含结算草稿说明。三类文件都展示了 `__KEEP__`、`__CLEAR__`、`__EMPTY__`、`upsert` 和 `delete`。常用模板写清「留空保留原值」「所在行选删除」即可。确需清空字段时提供明确的中文操作。系统身份和原版本由文件自动携带，工作表之间的稳定关系仍须按整行排序和插行验证。
- **打开报表直接看到数据。** 实际下载的需求、结算及档距报表都把「报表标记」放在第一张可见表。把业务数据放在第一张，把范围及生成时间放在业务页顶部。用隐藏标记识别报表并给出正确回导入口。
- **每个阶段只给当前动作。** 选文件时显示「选择 Excel 文件」。校验后先显示「新增 N 条、修改 M 条、X 条需处理」，再展开字段差异。先提示问题位置和可执行的修改，默认整批检查通过后保存，保留按单据提交的高级选项。用户点「保存 N 条需求」「保存结算草稿」即可理解实际效果。处理结果列出成功与待处理项，并提供打开记录或继续修正入口。版本、权限、引用及重复判定由系统在正式提交时复核。

## 其他业务界面

| 主入口 | 可简化的操作 |
| --- | --- |
| 工作台 | 首屏以当下可办的事项和补正入口为主。费用统计和框架汇总继续集中在分析区，待办条数与「查看全部」靠在同一位置。 |
| 专业需求 | 保留状态页签作为状态筛选的唯一入口。批量栏只展示对所选需求实际可办的动作，并说明部分记录因何不能办。按列筛选、清除条件、已选导出沿用系统统一位置。 |
| 子项目管理 | 承接需求表里，需求编号与「查看需求」目前进入同一详情。保留编号入口，把解绑及限制放到真正能办理的位置。概览直接给当前角色下一步，正式情况与以往版本在历史查看。 |
| 年度框架 | 列表已有清楚的「新增年度框架」和名称入口。关联项目或协议应带回原框架及滚动位置。 |
| 执行协议 | 用同样的档案与关联导航。进入某项目时明确「查看项目」和「办理费用」的不同去向。 |
| 费用与结算 | 「实际费用」「结算单」「费用核对」现在只跳转长页面的位置。改成明确选中的页签，保留项目结算总览和正在办理的单据。默认显示「草稿」「待审核」「已批准」「已退回」，把实测出现的「第 0 版 · 有草稿」和历史版次分开。 |
| 输电设备台账 | 导入、导出按当前设备分类选好范围。把「搜索名称或真实属性」换为该页实际可查的字段，例如线路名称、杆塔号。 |
| 物资管理 | 新增、查看、编辑路径已经清楚。搜索提示显示实际支持的物资名称、型号或规格。 |
| 作业标准 | 基本定义始终显示业务必填内容，需要特殊录入或计价时再编辑附加属性。保持从需求回查当时采用的版本。 |
| 参考价格 | 编制页同时显示「保存前检查」和「保存」，而保存本身会调用检查。主按钮只显示「保存」，把用于核对金额的选项写成「试算」。缺项后定位到对应页签与字段。 |
| 基础数据 | 单一「包含已删除」选项目前藏在「筛选」里。各列表统一放在筛选区并明确标出已应用条件。「新增根单位」可改成常用的「新增一级单位」，选中单位再提供「新增直属下级」。 |
| 系统管理 | 访问日志突出查询结果对应的条件与下载范围。请求方法、状态码和排查字段在有需要时查看。 |

## 实施与验收顺序

1. 先修影响数据范围和重复办理的问题。验证同一筛选下导出的业务编号完全匹配。勾选一张结算时导出一张。相同工作簿重复上传能够打开上次结果，继续处理时只带待处理行。从财务点左侧项目入口直接显示列表。
2. 收口导入主流程和模板。以单位置需求、档距、新增总额结算各走一次。下载模板后从第一张相关工作表开始。错误页面在当前步骤可重新上传。网页和问题表使用相同中文字段。正式结算草稿仍由单独的提交与审核环节生效。
3. 统一其余页面。按角色核对同一列表状态的主要按钮、禁用原因、详情入口和返回。填完规则即可保存，系统自动检查。需要计算示例时再选择试算。Windows 实机按现有安排暂缓。
