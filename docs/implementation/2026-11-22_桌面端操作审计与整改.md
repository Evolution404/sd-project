# 桌面端操作审计与整改

本轮以隔离演示库和桌面浏览器为准。对照十二个主入口检查了主操作、列表与子页签、详情、查询筛选、关联跳转、权限和退出。桌面交付范围见 [开发约束](../../AGENTS.md#桌面端交付范围)。

| 入口 | 复验与整改 |
| --- | --- |
| 工作台 | 从「在办项目」进入列表后，明确标出已批准及变更中的筛选范围，可一键清除。待审核结算从待办打开后可以返回工作台。 |
| 专业需求 | 状态页签和工作量筛选继续使用各自的业务口径。问题描述作为详情入口，列设置不能隐藏；需求状态始终可见。通过需求打开承接项目后回到原需求详情。 |
| 子项目管理 | 复验六种状态页签，保留项目名称详情入口。关闭通过链接进入的详情后清除对应定位，刷新仍停留在列表。 |
| 年度框架 | 状态可按中文选择，保留业务名称详情入口。读取失败时保留上次结果并提供重试。 |
| 执行协议 | 检查新增表单、关联导航及关闭。状态筛选和读取失败处理与年度框架一致。 |
| 费用与结算 | 按界面金额筛选。草稿详情显示当前草稿和草稿明细；有审核记录时显示最近一次审核及可用的退回原因。项目与跨项目查询统一费用作废、结算及核对状态。返回时恢复原单据与筛选。 |
| 输电设备台账 | 复验线路、物理杆塔、逻辑杆塔、档距页签，保护各类详情入口。状态和线路类型从中文选项选择，档距长度按米、高度按米筛选。 |
| 物资管理 | 物资名称始终可用于打开详情。「有效」筛选只保留有效记录。 |
| 作业标准 | 检查操作类型、作业对象及新增操作类型的分区。正式定义选择类字段按中文选项筛选。 |
| 参考价格 | 检查新增规则、适用条件、计价方式和退出。规则状态、作业方式和计价模型按中文选项筛选。 |
| 基础数据 | 电压等级搜索提示与当前数据一致。归口单位的已删除筛选直接可见，关联项目按六态显示，点击项目名称打开详情。组织树展开时避免节点因动画移动。 |
| 系统管理 | 检查用户与角色、IP 白名单、操作审计、访问日志。切换子页不会继续显示上一类记录。读取失败保留可见提示并可重试，审计时间及访问路径详情入口保持可用。 |

## 桌面实操

- 用筛选器选「有效」，确认物资列表仍显示有效记录。进入电压等级和归口单位，检查对应搜索提示和已删除筛选入口。
- 跨项目结算输入 ¥166.00，列表只留下 JS-000002。打开后显示「当前草稿」。从项目财务返回，原单据及金额筛选立即恢复。
- 从工作台「在办项目」进入项目列表，清除筛选后返回全部范围。需求的「问题描述」「需求状态」均保持显示。
- 管理员复查十二个入口。编辑账号可新增需求，审核和只读账号的需求列表不显示新增入口，三种非管理员账号不显示系统管理。

自动化回归共通过 265 项，浏览器门禁的 62 个脚本分批执行并复验了本轮修复相关路径，性能门禁通过 6 项。数据库 479 项结构检查通过，Schema113 结构保持原样。两个标黄项目的浏览器流程复验结算修订、费用核对、结项及重启后回查。
