# 杆塔性质与材质字典：实施验收

## 正式业务裁决
基础数据新增杆塔性质、杆塔材质，内置性质为“耐张、直线”，内置材质为“角钢塔、钢管杆”。物理杆塔的原“塔型”正式更名为“杆塔材质”，不得直接输入任意文本。

## 数据库与维护
- 统一复用字典根身份与正式版本机制 dictionary_items / dictionary_item_versions，分类为 tower_nature 与 tower_material。管理员可新增、编辑、停用、追溯；首次管理员初始化自动创建四项并保留真实版本和审计。
- physical_towers 与 physical_tower_history 分别引用 tower_nature、tower_material 字典的稳定ID，保留历史快照。逻辑塔关联实体，按同一物理塔取性质；字典当前名称变化不会改变引用身份。
- 两个字段采用受控选择，跨字典、未知或停用身份拒绝新增；已有合法历史采用项允许保留。显示层投影当前中文名称，代码字段只在持久化与业务匹配中使用。
- Excel设备台账导出展示中文名称，导入预检将名称或身份精确解析为当前有效字典ID；同塔多回不因改字典产生新物理实体。参考价格规则适用杆塔材质与台账一致。
- Schema113为唯一DDL；当前纯开发阶段隔离测试使用新结构，不新增旧塔型兼容或迁移技术债。

## 本轮验收
- 应用单元/API/领域/Excel 194/194通过；Schema113设计契约475/475、78张表、251个触发器和732个字段通过；性能4/4通过。
- 新增 tests/api/tower-dictionaries.test.mjs 验证四个内置选项、正式字典版本、物理杆塔拒绝错误身份、停用新引用拒绝及已登记历史保留。
- 新增 tests/e2e/tower-dictionaries-browser.mjs 验证两个基础数据页签、创建自定义材质、物理杆塔选择、编辑字典后动态显示与身份保持；整体43个浏览器脚本通过。
- Windows/macOS宿主打包验收与Windows10真实实机验收分开记录，不用宿主验证伪称Windows实机完成。
