# R0 正式录入基线与例外台账

基线 `620abf295540ef97051d71ca78fb5414ba30e97d`。以下为源码审计加已执行浏览器取证。字段按办理入口列示，API 路径对应 `server/platform/http/routes.ts` 和各领域 `http.ts`。所有查询沿用有来 CrudPage/CrudTable/CrudSearch、Element Plus 表格或详情；动态路由许可由 `server/modules/management/menu.ts` 决定，写入权限仍由对应服务独立校验。

## 弹窗处置

| 现有入口 | 处置和依据 | 复验 |
| --- | --- | --- |
| NativeRecordPicker、DemandTowerQuickPicker、EquipmentReferenceField、项目需求选择 | 搜索并核对已存在对象，在回填前确定业务身份。重复名称、共塔和端点关系需要独立列；保留选择浮层 | 需求、设备、项目、候选跨页浏览器 |
| 需求重复核对、换正式操作定义 | 正式需求比较、独立保留依据、确认替换草稿，保留焦点和草稿 | 需求及长表单专项 |
| 需求位置属性、预计物资逐项移除、每需求批准物资按钮、子费用替代表格 | 录入缺陷。歧义标签需结构化业务值；在同工作表处理普通编辑和成组移除 | R2、R3、R4 |
| 项目审批和结项核对、结算历史批准切换、待办退回、费用作废和删除、账号禁用 | 有意改变正式状态或采用事实，显示对象、锁定版本、影响及理由；保留确认或独立办理 | R3～R5、R8 |
| 实际费用、核对、普通科目、设备及物资普通资料、作业标准、价格、资金及系统普通资料 | 当前单条录入，批量入口需要领域权限、同源校验、预检及版本控制，待对应阶段治理 | R5～R9 |
| 整基更换、同塔/主支线、档距端点、组织跨级移动 | 独立关系命令和影响复核，普通字段工作表不得绕过 | R6、R8 |
| 密码、角色和数据范围授权、访问限制总开关 | 安全操作必须明确授权并立即复核影响；普通列表不暴露凭据 | R8 |
| 业务附件、历史追溯、导入预检和冲突确认 | 按采用版本读取独立证据，导入须在正式写入前核对结果；保留弹窗、抽屉及失败恢复 | R9 和正式业务回归 |
