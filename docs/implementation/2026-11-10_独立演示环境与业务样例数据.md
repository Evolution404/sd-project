# 独立演示环境与业务样例数据（2026-11-10）

## 一键启动

在 `项目仓库` 运行：

```sh
make demo
```

打开 **http://127.0.0.1:8788**；演示账号 `demo`，密码 `demo`。也可运行 `npm run demo`。只生成数据不启动网页：`npm run demo:seed`。

**演示数据库**：`data/demo/schema113.sqlite`。**正常数据库**：`data/schema113.sqlite`。两者彻底隔离；正常的 `make dev` 不会自动导入虚构数据。本机演示服务固定监听 `127.0.0.1`，不能作为局域网或正式环境使用。所有演示线路名称、物资型号与参考价均为虚构，不得用于真实工程或结算。

首次执行只接受空的演示目标目录；重复启动保留已修改的数据，不重复插入或清空。没有演示标记的现有目录、被篡改的演示标记均拒绝覆盖。演示模式固定账号与密码均为 demo，禁止随机生成及环境变量覆盖。已有演示账号若仍为旧口令，应先备份并通过正常账号修改流程调整，不得为修改凭据而删除或重建演示业务数据。正式环境账号不受此规则影响。测试使用独立临时目录，绝不使用真实业务库。

## 建议体验路径

1. **输电设备台账**：浏览两条线路及8基杆塔、6个档距。
2. **作业标准与参考价格**：查看操作类型与作业对象、固定单位、施工难度、常规和复杂施工报价。
3. **专业需求**：查看青峰线防鸟装置缺失、河湾线绝缘子更换、青峰线导线缺陷。
4. **年度框架与子项目**：第一个项目已批准，第二个项目处于待批准阶段，可继续操作。
5. **实际费用与结算**：第一个项目参考价 **228.00元**、批准预算 **500.00元**、实际费用 **274.00元**、第一批已批准结算 **108.00元**；第二批结算草稿可继续核对提交。四种业务金额彼此独立，不强制相等。

## 技术与验收

- 用统一 application/catalog/repository 业务方法在单事务内创建演示业务记录，没有平行 SQL 写入路径。
- `tests/api/demo-seed.test.mjs` 验证首次初始化、价格金额、关联完整性、重复启动保留修改、拒绝覆盖任意非演示数据、HTTP 登录。
- `tests/e2e/demo-browser.mjs` 验证浏览器登录、线路、杆塔、需求、子项目及参考价可正常查看。
- 当前正常数据库首次配置前后 SHA-256 相同：`20d7d4c28a3ac94e562dc87e8de1af591ea9515b063a15e195b611efb45113e0`。**没有触碰原数据**。
- 当前正常库存在既有业务数据，如果正式结构需要升级，应另走原有受控备份/升级，不让演示初始化脚本触发自动迁移。
