# 结算报表与桌面办理整改验收

本轮从 `b0934e0` 复查七项审计问题。数据写入与故障复现使用独立测试库，Computer Use 使用隔离演示实例。

| 操作 | 改动与验收 |
| --- | --- |
| 工作台统计 | 月度费用、季度费用和年度框架使用同一项目范围。测试项目登记 123.45 元并在结项后归档，三处同步排除。归档项目的正式费用仍可查询。 |
| 结算报表 | 结算单逐单列出草稿、最近提交和生效金额。独立「项目结算汇总」每项目一行，按项目全量生效数据计算进度。金额与有基数的进度提供可运算的数值。实操下载三期单据形成一行项目汇总，核定费用 274.00 元、生效结算 108.00 元，进度 39.42%。 |
| 子项目报表 | 「包含已删除」同时导出正常与归档项目，归档行明确标识并保留财务数据。Computer Use 下载核对归档标识；隔离库回归覆盖已结项项目归档后仍带历史费用金额。 |
| 查看单据 | 跨项目详情和审核共用结算明细。显示结算方式、采用的批准版本、费用科目和需求。科目、需求和依据可换行阅读。解决量同时显示需求、数量和其采用单位。实操核对 XQ-000001 与 2 套。 |
| 审核结算 | 确认前完整读取对应版本的科目及需求。正式科目名称来自已采用的科目版本。读取失败可重试，确认动作在完整事实载入后提供。编制、审核和只读角色均按现有业务权限办理。 |
| 跨模块返回 | 从原项目查看关联需求再返回，保留项目、页签及本会话的勾选。Computer Use 从「已批准」选中一个项目并往返，原勾选及「导出所选」恢复。回归在长列表核对返回后的滚动位置。筛选改变和退出登录清除有关选择。 |
| 工作台办理 | 可办的立项编制、立项审核和项目变更审核直达已有办理页。有阻塞原因的事项进入补正相关页签。实操核对取消后回待办，回归覆盖保存、审核后回到工作台及任务状态更新。 |

门禁通过 266 项常规检查、479 项数据库结构检查和 6 项性能检查。桌面浏览器的 62 个脚本分批执行，最终调整后复跑相关路径。专项包括 `dashboard-batch.test.mjs`、`settlements.test.mjs`、`finance-direct-record-browser.mjs`、`finance-roles-browser.mjs`、`user-journey-navigation-browser.mjs` 和标黄双项目全流程。Windows 实机继续按既定安排暂缓。
