日期为 2026-11-23。目标工作树为 `sd_project-rewrite`，分支为 `codex/full-rewrite-20261110`。交接基线为 `ee609ac`，保留后续提交 `7e28a0f` 的操作历程和工作区修改。

## 设计和数据归属

- 原件由 Mac 上的 Google Chrome 打开。使用四行合成 CSV 激活原表格。实测表头高 38px，菜单宽 330px，候选行高 29px。检查了 `.column-heading`、`#columnMenu`、`openColumnMenu` 及搜索、应用、取消与排序行为。应用按钮采用候选搜索结果，取消恢复原状态。参考文件为用户本机 `本地受控文件`。
- 物资页 URL 持有页码、排序和已应用条件。`TabulatorGrid` 投影这些条件并管理列设置，`ExcelColumnFilter` 只暂存本次展开菜单内的操作。SQLite 使用同一套条件查询列表和候选，支持空值、中文状态名和按值计数；候选加载每页 100 项，摘要包含未加载的匹配项。服务器按候选搜索和勾选规则执行整个查询，270 项可以一键选择再排除单项。浏览器地址和 API 参数仍有有界的筛选条件长度。
- `BusinessDraftGrid` 使用 Tabulator 的区域选择、导航、编辑事件及复制入口。草稿操作记录按行身份和列保存前后值，最多 100 步。单元格提交和合法 TSV 粘贴各记一步。重放仅修改原步骤涉及的单元格并同步父表单，新的编辑清除重做分支。焦点离开网格后，外部控件按本身的键盘行为处理。
- 普通物资列表保留带筛选及排序箭头的单行表头，数据区只保留行分隔。需求预计物资查看采用业务清单。批量编辑才显示完整网格，激活单元格和区域均以单层边框标记。批量编辑的列标题和行首沿用当前主题底色。
- 物资批量编辑限定当前页的名称、型号、规格和备注，经原批量命令原子保存。需求预计物资修改预计数量，冻结单位精度、正式需求版本和原审核规则继续由原业务命令处理。只读边界与越界粘贴均在修改前整批拒绝。Schema113 无结构改动。
