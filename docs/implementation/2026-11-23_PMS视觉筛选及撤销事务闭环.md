## 当前统一设计

1. TabulatorGrid.vue 保留 Tabulator 6.7.1 数据网格、远程排序接口及现有服务端分页；单行标题通过 Vue/Element Plus 按钮复现 PMS 样式，不再使用 Tabulator 原生第二行 headerFilter:list。字段状态从同一套业务层 sortKey/sortDirection/filters 下发，表头以 ↑/↓、青绿色和无障碍标签持续表达已排序/已筛选。按菜单排序时调用 Tabulator setSort/clearSort，由 dataSorting 事件进入原 SQLite 列表查询。
2. ExcelColumnFilter.vue 使用 Element Plus ElInput/ElCheckbox/ElButton 和现有 filter-values 数据库去重候选 API；菜单布局尺寸、顺序和颜色来自本机 PMS 源文件，不新增第二套筛选数据协议。筛选先编辑候选集，再按“确定”更新原有 grid_filters；按“取消”不修改事实。
3. 普通查看没有 Excel 蓝色选区、单元格编辑器和即时写入；主动批量编辑才启用 BusinessDraftGrid.vue。
4. BusinessDraftGrid.vue 中 Tabulator 原有 history 覆盖单元格编辑，却不能与多行剪贴板写入及 Vue 草稿一致构成可靠的统一操作历史。现改为一套显式事务历史（最大100步）：普通单元格 dataChanged 当次提交独立步骤；合法 clipboard paste 通过 paste 捕获标记整批事务并集中提交；恢复时经 Tabulator updateData 及原 syncChanges 同步父级 Vue 草稿与正式数量校验。按钮和 Mac/Windows 快捷键调用同一函数。
5. 每次粘贴仍先校验编辑范围、只读列和行边界，非法数据整批拒绝。数量单位精度及正式版本校验仍在原领域服务。无 Schema113 变更。
