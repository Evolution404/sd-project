# UI组件评估、视觉规范与迁移路线

日期：2026-11-09。系统：Vue3、TypeScript、Vite、Windows 10/11 离线 ZIP。

## 核查结论

| 候选 | npm版本（11月9日核验） | 许可证 | 评价 |
|---|---|---|---|
| VXE-Table v4 | 4.23.16 | MIT | Vue 3 专业表格首选；高级复制粘贴、框选等商业扩展不能未经授权使用 |
| shadcn-vue | 2.9.0 | MIT | 苹果式视觉可塑性强，但组件源码由本项目维护，升级成本高 |
| Reka UI | 2.11.0 | MIT | Vue>=3.4，支持无样式无障碍基础控件 |
| Naive UI | 2.45.3 | MIT | Vue3一体化表单库，升级与复杂选择器维护成本较低 |
| motion-v | 2.11.1 | MIT | Vue3局部动效，不能对上万行整表做动画 |
| Element Plus | 2.14.8 | MIT | 当前稳定组件库，可暂作过渡，不再依赖全局深绿色视觉 |

## 已实施的全局设计令牌

主色 #3478F6，深色文本 #24314A，次级文字 #74829A，页面背景 #F5F7FB，边框 #E7EBF2。强调卡片可读性、表格密度、适度圆角和柔和阴影，禁止大面积墨绿色、背景虚化和无意义发光。

导航默认 240px、折叠 68px、调宽范围 208～320px；使用 Element Plus 图标与悬停提示；状态存入 localStorage；主内容宽度联动；窄屏抽屉与 reduced-motion 支持。已实现跟随系统/浅色/深色三态主题，本机浏览器测试通过；Windows 实机外观验收仍需补充。

## 三个页面的验证试点

1. 工作台：全局色彩、导航、指标卡片层次；明暗主题浏览器专项通过；待补低性能 Windows 截图。
2. 输电设备台账：BusinessTable 共享适配层、按业务字段列展示，关系明细、SQL 搜索/分页、持久化列设置；已在独立数据库验证 1000 线路和 10000 逻辑塔；VXE 虚拟列表未安装。
3. 子项目页面：列表、已关联需求、批准范围与批次/项目参考费用、财务费用科目/实际费用/结算/核对/解决需求明细均复用 BusinessTable；可编辑批准草稿、附件、Excel 预检及报价明细均已接入统一表格。

## 正式迁移路线

阶段A：当前 Element Plus + BusinessTable 保证核心逻辑稳定与 Schema113 测试，完成全部表格、父子级联及表单验收。

阶段B：在隔离台账试点验证 VXE-Table v4 免费能力、虚拟滚动、筛选、列宽、固定列、个性化顺序、导出匹配与中文环境。禁止依赖未明确授权的商业特性。

阶段C：以一个详情表单对比 shadcn-vue/ Reka UI、Naive UI 的无障碍、远程级联选择、弹窗校验、TypeScript、包体积和维护负担。先核定组件库接口边界与视觉 tokens，禁止两套完整业务控件长期并存。

阶段D：按模块迁移，每批必须通过 Node Test、Playwright、无原生 UI 严格门禁、Schema 113、Windows 离线打包/部署与键盘无障碍测试。调整门禁为组件库无关，不撤销。

当前决策：暂时保留 Element Plus，避免把一次性大规模 UI 库替换与业务数据治理绑定。

## 本轮 UI 交互调整

侧栏删除调宽按钮，使用右边界拖动、键盘调整、双击复位。表格统一启用真正可拖动列宽与表头默认单行。详细依据与剩余问题见《2026-11-09_UI交互审计_侧栏与表格列宽.md》。
