# 2026-11-09 设备台账 Excel 全流程治理与验收

## 范围及业务决策

当前系统是完全独立的输电项目管理系统，不考虑任何外部系统格式或编码。Excel 仅提供用户可理解的业务事实录入。线路、物理杆塔、逻辑杆塔、档距的稳定身份由后端负责，Excel 不要求手工编写身份或版本。

台账维护 Excel 采用三张业务表：

- **线路**：线路名称、电压等级、线路类型（主线/支线）、所属主线、主线接入杆塔、状态及架设方式。
- **杆塔**：线路名称、电压等级、杆塔号、实物属性、明确共塔的已有线路及杆塔；不手填物理/逻辑身份。
- **档距**：所属线路、起点/终点杆塔号、必要时起终点所属线路、状态、输电中心管辖长度（米）；长度空值=未知，0=明确无管辖长度。

业务单据可通过一个工作簿建立，列的可见名称仅为中文，系统身份和版本为隐藏保护字段。旧版机器后缀列头仍可解析，不会要求用户重新录入历史工作簿。报表与可回导维护表独立，报表不能当作维护数据提交。

## 依赖与原子性

系统自动按引用关系决定创建顺序：主线 → 主线接入杆塔 → 支线 → 支线杆塔 → 档距。允许工作簿按任意行顺序填写，但不能存在引用循环；预检会给出原始工作表和行号。

同名线路、同线路重复杆号、同档距重复或起终点互换重复、共塔歧义等一律停止自动判断，不在预检或保存过程中制造虚假的实体关系。主线档距的两端属于本线路；支线档距可以连接自己的两个端点，也可以通过唯一明确的主线接入杆塔跨线连接。任何其他跨线连接在预检阶段拒绝，数据库外键与触发器继续提供最终约束。

预检不修改正式业务。提交前重新准备并校验，按原有逐单据事务或用户勾选的整批全部成功/全部回滚执行，保留幂等、乐观锁及正式版本历史。

## 导出和界面

设备台账各选项卡使用统一 Excel 工具；线路/杆塔/档距列表支持勾选项导出。勾选线路时导出的维护工作簿包含该线路的杆塔及档距。维护导出隐藏原 ID 和原版本，用户只改业务字段，回导保留原对象身份、历史及关联。主支线关系及真实档距端点可往返保持。

## 自动化验收

新增专项：tests/excel/assets-topology.test.mjs

- 同一文件中打乱行顺序新增主线、接入塔、支线、支线杆塔、主线及支线档距。
- 跨线支线合法接入保持引用关系，正式历史、外键一致。
- 带隐藏身份的完整维护导出、无修改回导不产生伪版本、修改长度形成新版本。
- 线路选择导出包含相关杆塔、档距，字段可读，不出现可见数据库英文字段。
- 拒绝反向重复档距、错误支线、无效跨线端点。
- 已有需求与结算 Excel、同塔多回和事务回滚测试照常通过。

## 剩余外部验收

真实 Windows 10/11 x64 实机 Excel 文件交互仍需现场验证；Mac 浏览器及打包验证不能替代 Windows 实机验证。
