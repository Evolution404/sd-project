# sd_project｜Schema113 已知问题治理及 UI 全面审计、操作升级实施记录（2026-11-09）

## 一、审查对象与裁决原则

基线 `ca7d225`，覆盖工作台、输电设备台账、专业需求、年度框架与子项目、执行协议与资金、作业标准与参考价格、实际费用与结算、系统管理共八个入口及共用表格、选择器、弹窗、历史、导入组件。UI 仍采用项目既定的 Vue3 + Element Plus，不引入第二套业务组件、不增加必须手填的数据库内部字段、不牺牲正式数据版本和审批约束。

交互统一顺序：**选择要做的业务动作 → 自动推导设备/定义信息 → 只补充不可推导的事实 → 保存或正式确认 → 显示可核对的结果与历史。** 默认提供最短操作路径，高级项按需展开。正式核定和删除等高风险动作必须明确确认；普通编辑不额外增加无效确认。

## 二、已知数据库问题治理

### 旧价格特征版本规则无法正式停用

旧 Schema113 的 `reference_price_factor_definition_guard` 不区分改价与停用：只要追加价格版本，历史关联的价格特征非最新版就被拒绝，致使规则不能通过正式版本停用。

已治理：
- 只对**前版有效、当前停用、且标题、操作与固定单位版本、完整价格、适用条件、价格来源和日期等全体业务定义字段完全一致**的正式版本免除「须引用最新价格特征」检查；其他修改继续保持严格完整约束。
- 应用层 `save` 和保存前预检查均仅对纯状态停用采用例外；修改其他字段仍需明确升级正式操作定义和价格特征。
- 在参考价格列表和详情增加**停用**入口：一键仅提交状态变化，记录理由；**删除**仍是独立审计墓碑，不制造价格版本；原报价记录与引用保持。
- 参考价格当前视图补齐价格来源、价格日期、计价依据、版本原因与时间，避免编辑既有规则时这些字段莫名空白。
- 受控 `upgradeSchema113` 认领精确旧结构指纹 `c666bc3dbd3392af5bcac585147a9920ed897c0c7ef641ae692815b692d4f044`，必须显式执行，先进行完整数据库备份、恢复演练、数据事实比对、外键与完整性检查；启动流程不暗中升级。
- 回归覆盖旧库升级、正式价格条件原样保留、停用新版本、拒绝未升级改价、重复升级为 `already_current`，以及 Schema113 权威数据库审计。

## 四、可执行的 UI 操作升级方案

**P0｜核心工作路径最短化（已落实/保留）**

- 用户选择操作类型后，自动获取唯一作业对象、正式固定单位和适用设备位置类型，优先只填写设备与工作量；无合法默认的情况由用户确认。
- 一个业务行为只有一个主按钮；查看详情是正常文档流中的模态详情，修改/删除作为次操作，不为数据库的每一张表单独增加步骤。
- 参考价格独立区分修改、停用、删除；停用只需确认，不要求手动进入全部计价标签重新维护。

**P1｜无损编辑（本轮实现）**

- 作业标准、需求、项目与资金、财务、系统管理五类正式编辑弹窗使用同一未保存提示规则；关闭按钮/键盘 Esc/取消按钮一致。
- 无修改直接取消，不弹多余确认；有修改则可选择继续编辑或放弃；保存成功直接关闭，不再提示未保存。
- 多标签价格/操作定义保存失败时切换至错误字段所属标签，定位报错，不要求用户逐页查找。
- 同一页面连续新建多条记录时，服务端持久化和表格刷新均完成后才关闭旧编辑弹窗与释放保存锁，避免前一项刷新未完成时直接吞掉下一次保存；浏览器覆盖快速新增线路、杆塔、共塔及重复杆号撤回。

**P2｜强可理解的数据表格（本轮实现）**

- 关联字段直接显示业务名称而非“已关联”或内部 ID；必要时才在详情中显示历史版本/编号。
- 列排序、筛选、拖动宽度、用户自定义显示与顺序采用同一 BusinessTable。
- 有筛选时显示“已筛选 N 列·清除”，无结果时明确提示并提供恢复入口；列宽偏好恢复后强制重新计算布局，保持表头不折行。
- 数据/网络错误必须能感知与重试；远程选择只在查询失败时增加提示，正常交互不改变下拉控件的渲染链。

**P3｜正式操作可追溯（本轮实现/保留）**

- 新增、编辑、停用、删除、核定有清晰不同文案；改变正式审批结果时要求理由/版本校验，状态与不可变历史保持相符。
- 操作权限在页面可用性和服务端两端共同校验。已删除历史只读，附件和完整历史仍可访问。

**P4｜后续视觉设计方向（不是本轮未完成的功能承诺）**

- 保持 Element Plus 单一组件体系，使用当前白底/浅蓝、深色变量与统一间距、圆角、细边框及轻动效，不另起 Vue UI 库替换工程。
- 视觉上继续以高信息密度但低输入负担为准；业务流程可以按批次/场景扩展而不能添加无业务必要的新手工步骤。
