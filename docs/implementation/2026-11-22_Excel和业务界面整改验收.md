# Excel 和业务界面整改验收

对应 [2026-11-21 易用性审计](2026-11-21_Excel和业务界面易用性审计.md)。浏览器实操使用单独的演示库和模拟工作簿。

## 逐项整改

| 场景 | 实际操作和结果 |
| --- | --- |
| 按筛选导出 | 点击「导出 Excel」直接获取当前已应用筛选下的全部页。需求报告回归核对状态页签、问题描述列筛选、报表范围和实际记录。 |
| 勾选导出 | 需求、子项目、设备及结算的勾选项由「导出所选」直接下载。跨页勾选仍保留，列表查询条件独立保存。大量勾选也能传递完整清单，勾选为空时不会扩大导出范围。 |
| 批量修改 | 「用 Excel 批量修改」在同一窗口提供下载已填数据、上传检查、查看改动和保存。默认允许修改已有记录。 |
| 模板 | 首个工作表与入口对应。需求和作业位置有配套示例。结算首表优先填写本次金额，按需补充子费用和需求解决量。用户填写金额单位为元，档距长度单位为米。读数报表在第一张工作表显示业务数据、范围、条数和导出时间。 |
| 导入纠错 | 选中一个文件后显示文件名。错误显示工作表、行、中文字段名和修正提示。可下载标出错误的原表，待处理入口支持原处重传。部分保存后，待处理副本剔除已完成记录及相应明细。 |
| 重复上传 | 同类型、同项目内再次上传已处理的同一文件时回到上次结果。仅已完成且全部为新增结算的文件可经明确确认后用作新一期。正式保存时复核，避免两个窗口同时检查后重复写入。 |
| 结算状态与入口 | 财务页使用「实际费用」「结算单」「费用核对」「需求解决量」页签。结算列表直接显示草稿、待审核、已批准、已退回等业务状态。未批准项目在上传前显示办理条件，草稿仍经复核和批准才形成生效金额。 |
| 模块导航 | 左侧「子项目管理」回到列表及原查询。办理页返回保留原项目和来路。从年度框架或执行协议进入关联档案后回到原档案。项目名称打开详情，另有「办理费用」入口。承接表仅保留一个需求详情入口，「解除承接」显示相应限制。 |
| 访问日志 | 关键词、起止时间放在首屏。输入与现有结果有差异时提供「应用条件并下载」。刷新继续使用已应用条件，结果区显示范围和条数。 |
| 其他界面和指引 | 工作台将待办置前。设备、物资、基础字典等搜索提示写出可查字段。参考价格保存时自动检查，需要核算金额时可单独试算。组织树使用「新增一级单位」「新增直属下级」。更新 Excel 指引和课程文案。 |

## Computer Use 实操记录

- 在已批准项目的「结算单」页只填写 ¥55.00 并保存草稿，取得 JS-000003。同一文件重新上传后回到该单据。勾选后下载的报表仅含 JS-000003，第一张表顶部标明勾选范围和一条记录。
- 在需求表模拟一条可保存记录和一条填写 1.5 套的记录。系统在作业位置第 3 行标出工作量问题。先保存通过项后下载待处理副本，已完成记录及其位置为空，待处理工作量仍为 1.5。修正为 2 后重传，只新增一条需求。
- 从档距页下载台账模板，实际文件第一张工作表为「档距」。在访问日志输入关键词后直接下载，文件三条记录均匹配，页面也显示已应用关键词及三条结果。
- 从财务点左侧子项目入口，列表直接显示。储备项目财务页提示批准后才可导入。在年度框架打开关联协议及项目，关闭详情后回到原框架。

## 数据与验证范围

Schema113 结构保持原样。已有导入结果继续按原记录回查。早期结果缺少原表行号时，界面提供问题清单，并提示只把待处理记录填入新表，避免已处理记录再次写入。

常规检查包含 265 项自动化用例。数据库结构三个门禁共检验 479 项契约，性能门禁通过 6 项。浏览器检查覆盖四类权限、十二入口、Excel 文件往返、财务页签、结项保护和独立实操。

Windows 实机验收按既定安排暂缓。正式包和演示包的宿主解包验证、源码基线及文件摘要以发布清单为准。
