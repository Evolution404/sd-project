# 需求详情操作区按业务状态分级（2026-11-23）

## 本轮业务决定

需求详情按办理优先级展示操作，不以「更多操作」任意收纳高频动作。调整范围限于桌面前端，不修改需求状态机、服务器权限、批准范围或财务模型。

- **下一步主动作**：待确认／已退回为「确认并待承接」；有效未关联为「关联子项目」；已关联为「进入承接项目」；已取消无主动作。每次至多出现一个主要蓝色按钮。
- **高频次级动作**：未取消且未删除的需求直接显示「参考价试算」「修订需求」，不随窗口缩窄强制移入菜单；按钮组可换行。试算保持完整需求口径，项目应从批准范围按承接范围核价。
- **记录查阅**：「历史记录」移到需求编号和正式定义版本旁边。原采用操作定义链接仍保留在需求定义分区。
- **低频状态变更**：只有当前状态允许出现的「退回修改」「取消需求」「删除需求」才进入「其他处理」。已承接需求没有退回／取消菜单，后端独占承接保护不变；已取消仅管理员可见删除入口；无可用管理动作时隐藏整个菜单。
- **权限与指引**：未具办理权限时主动作或常规编辑显示禁用和权限说明；参考价只读试算及历史查阅仍可访问。使用指引动作锚点保持稳定，退回的展示名称和训练课程同步修改。
- **状态刷新**：沿用需求列表加载时对打开的需求详情重新获取最新正式事实；状态切换后立即更新按钮。
