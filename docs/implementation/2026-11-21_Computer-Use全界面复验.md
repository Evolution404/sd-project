# 2026-11-21 全系统 Computer Use 复验

在本机应用内浏览器，使用与内网导入数据分开的临时演示库，通过菜单、页签、表格、详情、表单和正式办理控件实际操作。管理员、编辑、审核和只读四种身份分别登录。表内记录了本轮实点的入口与结果。

| 界面 | 实际操作和结果 |
| --- | --- |
| 工作台 | 切换年度框架、月度及季度费用报表，刷新待办。批准结算后，框架报表更新累计进度。核对浅色和深色切换。 |
| 专业需求 | 切换全部及五种状态。从同一需求正式确认、退回、修订预计解决时间并再次确认。查看历史，核对多位置及预计物资选择、离开未保存表单、参考报价试算及正式确认。对新导入的需求批量确认、整体关联项目，状态变为已承接。 |
| 子项目管理 | 切换全部及六种项目状态。从需求新建项目、选择年度框架与执行协议并承接同一需求。批量入库、首次批准、变更再次批准、差额结项。恢复默认列后保留已批准页签和选择，导出所选工作簿。核对历史版本对比及已结项范围的解绑限制。 |
| 年度框架 | 从名称打开档案及关联项目、协议、结算进度。查看修改表单和版本历史。删除预检列出受影响的 10 个项目与 2 份协议，确认前退出。 |
| 执行协议 | 打开档案，核对所属框架和关联项目，检查编辑、历史和删除预检。新建子项目时，框架及协议下拉选项只显示业务名称。 |
| 费用与结算 | 在项目工作区建立科目、核定实际费用，办理总额结算、按子费用结算及正式核对。从跨项目查询分别打开实际费用、结算及核对记录。走通退回、原版重提、批准、正式修订。导入总额结算只产生草稿，仍须送审和批准。 |
| 输电设备台账 | 查看线路、物理杆塔、逻辑杆塔、档距的列表、详情和新建表单，回查历史和共塔选择。正式执行一次整基更换，原实物退役并保留历史。Excel 导入一条线路、两基杆塔和一处档距，从结果直接进入档距详情，核对管辖长度 550.5 米。 |
| 物资管理 | 新建物资、修改规格，核对版本历史。检查删除影响零引用，确认逻辑删除。通过系统审计找到此次操作。 |
| 作业标准 | 打开操作类型和作业对象，逐项点击操作类型的四个编辑页签。核对对象位置、归属单元、附加属性定义和正式版本的中文内容。 |
| 参考价格 | 打开规则详情和版本历史，复制规则后逐项查看三个编制页签。触发条件重叠核准提示，取消保存。到需求页面核对引用该类规则的正式参考报价。 |
| 基础数据 | 切换七个分类，打开各字典新建表单。组织树打开新增直属下级和调整上级，核对变更前后路径后退出。 |
| 系统管理 | 切换用户、IP 白名单、操作审计和访问日志。核对账号表单与各角色选项、访问限制表单、独立审计详情和访问记录详情。实际下载访问日志，113 条均命中已应用的 `/api/catalog` 筛选。 |

## 实际办理结果

- 验收项目 `XM-000017` 始终承接需求 `XQ-000003`。先批准预算 ¥1,800.00，正式变更后 ¥2,200.00。核定实际费用 ¥1,000.00。第一期总额结算 ¥600.00 经退回、原版重提再批准，第二期按子费用批准 ¥380.00。结项快照保留累计 ¥980.00、结算进度 98%、待结算 ¥20.00、待核对费用 ¥620.00 和未解决工作量 1。项目结项后，最新版批准范围中的需求继续保留承接关系。
- 青峰线防鸟装置演示项目导入总额结算 `JS-000005`。预检显示「结算单 · 第 2 行」「按项目总额」和 ¥55.00，费用明细与解决量均为空。导入后项目已结 ¥108.00、进度 39.42%。首次批准后累计 ¥163.00、59.49%。修订申请 ¥65.00，待审核期间原 ¥55.00 继续有效，批准后项目累计 ¥173.00、63.14%，其中按总额结算 ¥65.00。
- 专业需求 Excel 下载模板、错误预检、下载问题清单、改正后正式提交和回查均实际完成。工作量 1.5 套被拒绝，改为 2 套并使用独立试验位置后新增一条需求。已承接页签下载维护表，18 个需求编号逐个匹配当前已承接身份。附件实际上传、下载、逻辑删除并从历史回查。
- 十二个主入口各从界面点完一轮五步导览，共 60 步。编辑能编辑但不能确认，审核完成正式需求确认且不能编辑，只读能查详情与历史。管理员操作范围包括系统管理。

## 现场发现、修复与复验

| 发现 | 修复后的本机浏览器结果 |
| --- | --- |
| 项目版本对比将首次批准的「纳入范围」事件当成后续被移除的范围 | 比较两个正式版本时采用各自的批准范围。对比同一项目第 1 版与第 2 版，只出现真实预算及批准依据差异，原先错误的移除记录消失。首次批准的纳入事实继续在对应事件中显示。 |
| 作业标准及参考价格详情展开内部字段或技术值 | 复用正式历史的结构化投影，按中文业务字段展示附加属性的归属、录入方式、计价要求、选项及价格适用条件。 |
| 整基更换表单重复显示「新杆塔」 | 在分区标题说明填写的是新杆塔，字段直接显示「杆塔高度（米）」等业务名称。 |
| Excel 批次完全无效仍可点提交，问题和总额结算差异显示技术字段 | 零有效单据时提交禁用。错误提供字段或工作表行定位，总额结算显示真实工作表位置及中文结算方式。用错误需求和可批准结算各复验一次。 |
