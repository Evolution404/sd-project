## 已定位的问题

|问题|级别|根因|处理和验收|
|---|---|---|---|
|数据库脚本越过边界|阻塞|Demo 及真实导入、字典补齐直接操作 SQLite|数据库模块提供检查点及固定台账统计；工程边界实测通过。|
|结算错误定位|阻塞|程序选中单元格时选区文案可能仍是上一步提示；测试包含旧文案|原生选中后同步状态并交还键盘焦点。20 行回归验证错误定位、边缘滚轮隔离、数量、依据及快照。|
|物资版本定位|高|摘要与时间轴同时包含 V2|测试按时间轴版本核验相应型号，保留正式版本断言。|
|参考价格修订定位|高|字段独立整改后文案更新|在正式构建中检查操作版本 V1/V2、试算金额及保存后的版本引用。|
|标准视口滚动|高|20 行或默认列宽在标准视口可能没有双向滚动|通过原生分页和列宽变更建立可滚动场景，核验偏移刷新后恢复。|
|历史公开数据|阻塞|既有历史回归读取由业务文档摘录的数据|原文件本地留档，公开运行独立合成夹具，扫描拟发布源码与新增 Git 对象。|
|实物与边界端点|阻塞|部分历史源记录暂无可确认实物或现有 Schema 端点表示|逐条留存排除回执，保留待核状态和原始数据。|
|依赖审计|高|ESLint 旧版传递依赖存在中等级公告|升级至采用已修复依赖的 ESLint 版本，重新审计锁文件。|
