# 全系统治理实施记录

基线为重构分支 fd06fbc。本记录只列已经实施和验证的工作，交付矩阵按后续批次更新。

## 正式数据与查询第一批

- 结项核对单独读取。正式提交在事务内复核项目版本、批准范围、结项阻塞、财务版本及金额和需求解决量快照。结项拒绝后可以重新读取并确认。
- 同一份未获得响应的提交保留原请求标识。浏览器模拟服务端成功而响应丢失，保存重试只产生一笔100元实际费用。
- 下调费用时校验该费用的累计有效核对金额。项目内及跨项目结算列表使用同一状态判断。正式核对选择器按当前生效明细查询，显示费用科目和需求身份。
- 项目批准提示复用正式批准校验。工作台采用六态项目查询。结算报表明确分列草稿、最近提交及当前生效数据，解决量按各需求冻结单位单列，并批量读取生效数据。
- 设备维护Excel允许保留原已停用字典引用并更正无关字段。结算预检一次索引全部主单行。
- 已验证全量构建、24项相关服务及Excel测试、断线重试浏览器、跨页核对选择浏览器和项目办理、核对、差异结项浏览器旅程。

## 正式规则与边界第二批

- 提取独立结项应用用例，统一待结算和项目变更的阻塞提示。在应用事务与SQLite中双重检查下调后的实际费用仍能覆盖有效核对。结算审核预览显示受影响的核对，历史核对与当前有效核对区别展示。
- 工作台项目待办读取应用服务判断。项目内及跨项目列表接受同一中文结算状态筛选。财务详情区分费用计量数量与需求解决量。年度框架、执行协议及工作台按共同的有效财务事实汇总。
- HTTP按命名能力组装，Excel由专用批次与工作表解析接口支撑，训练证据取自已执行的批次动作。演示数据库诊断通过数据库模块。前端改为导入公开类型，门禁增加数据库连接、前端实现导入及Excel反向调用检查。
- 设备线路删除预检逐位置计入所关联的线路。系统操作审计采用数据库分页。项目与结算支持核对后继续编辑，并在随后提交时复核最新版本。项目档案负责资金归属写入，旧独立写路由撤除。
- 新增治理浏览器专项入口和发布验收入口。发布宿主验证与Windows实机验收分别统计。
