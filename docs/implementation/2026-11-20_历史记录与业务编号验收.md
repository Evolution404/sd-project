# 历史记录与业务编号验收

## 历史记录

业务详情共用时间线、事项详情、版本对比和关联凭据。历史查询按业务对象和原版本读取，时间用北京时间，金额用元，数量附采用的单位。每次载入返回十条摘要及选中事项。前端可以按人员、事项和日期筛选，打开关联版本后可以返回原记录。

| 入口 | 验收内容 |
| --- | --- |
| 工作台 | 进入待确认专业需求，沿业务入口查看该需求的历史。 |
| 专业需求 | 浏览修订、项目承接和报价确认。实测需求第 2 版修订后仍能打开采用第 1 版的 ¥240.00 报价，计价依据显示人工费与机械费。比较两版预计解决时间。 |
| 子项目 | 浏览首次批准的预算、需求范围和作业位置。正式变更读取当时批准的范围和预算，结项读取冻结结果。 |
| 费用与结算 | 验收第 2 版申请 ¥36,000.00 退回时第 1 版 ¥30,000.00 仍生效。专项检查随后批准第 2 版只增加 ¥6,000.00，项目进度为 36%。 |
| 年度框架与执行协议 | 从名称打开详情和历史。查看建立记录、额度与协议版本。 |
| 输电设备台账 | 核对线路的历史入口。档距记录按米显示，实物关系及整基更换列出相关回路。 |
| 物资管理 | 从名称打开物资历史。 |
| 作业标准、参考价格 | 在详情查看正式版本与所采用的定义、价格模型和历史依据。 |
| 基础数据 | 查看计量单位历史和历史数量格式。组织调整记录展示当时上级和路径。 |
| 系统管理 | 从操作审计的登记时间打开可读详情。访问日志详情提供业务结果，按需展开技术详情。 |

用隔离演示库通过 Computer Use 核对主要入口。管理员、编辑、审核和只读四个角色分别打开了专业需求历史。日志详情与原始业务数据继续执行服务端权限检查。浏览端可从项目和跨项目财务打开同一结算历史。

## 编号及选择器

新业务编号由服务端在创建事务内分配，采用类型前缀和六位数字起步。需求、子项目、结算分别为 XQ、XM、JS。项目变更、年度框架、执行协议、设备、物资、规则和基础档案使用各自的前缀。现有编号与业务引用保留原值。存量历史和逻辑删除记录占用原编号。演示数据版本升级为 6，启动演示服务时按现行流程归档旧演示目录，再按新编号生成示例。

共用选择器加载关联名称期间显示可读提示。年度框架、执行协议、需求及费用等选择器的默认标签是业务名称、费用事项和实际金额。同名框架可补充年度，同名协议可补充合同对方及生效日期。结算核对场景在确有歧义或主动按编号检索时显示结算编号。

通过 Computer Use 手输 XM-000001 并打开项目，复制操作显示成功。新建项目的框架和执行协议列表显示名称，正式保存测试项目后产生 XM-000017。验收使用独立数据目录。
