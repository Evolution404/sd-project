# DUX 添加作业位置：分页全选和筛选选择交互

## 一、设计裁决

- **表头层级**：“本页选择”列展示复选框，可选中或取消当前页全部可选记录。已选0条时未选，部分选中时半选，全部选中时已选；切换分页后状态依当前页重新计算。已录入需求的位置不再显示为新候选。
- **筛选层级**：顶部保留“全选筛选结果”，新增“取消筛选结果”。两者使用当前线路、位置类型、已提交的搜索条件和后端有效状态；涵盖符合条件的所有分页，不是只处理当前页。“取消筛选结果”不清理其他线路或其他条件下已选的位置。
- **整个选择会话**：跨页/跨线路已选记录保留；“清空全部已选”清理本次所有已选而不影响需求正文或已有正式位置。底部展示已选总数，逐条标签仅展示前30处以避免海量DOM。
- **数量上限**：一条需求最多5000处（含本次此前已加入需求的位置）。本页/筛选批量选择在提交前检查整体上限，拒绝超限且不产生部分选择；单条勾选同样限额。已有位置和重复物理身份去重。
- **并发安全**：批量请求保持操作开始时的线路、位置类型、搜索快照；切换过滤条件或关闭弹窗后，过期结果不得提交。分页查询时移除旧可选行，但不能清空分页总数导致翻页退回第一页。
- **可访问性与复用**：BusinessTable 仅为显式启用customHeader的列渲染自定义表头，其他列仍保留排序/筛选控件、列宽调整及设置。表头复选框有明确“全选本页／取消全选本页”辅助名称。

## 二、验收证据

专项浏览器 tests/e2e/location-selection-browser.mjs 已实测：
1. 甲线路122条设备，第一页100条、第二页22条：全选、取消、半选、跨页保留，翻页不重置；
2. 当前线路筛选结果整体选择与取消；乙线路3条独立选择，取消甲线路只清除甲线路，乙线路继续保留；
3. 清空全部与重新选择；已添加需求的3处位置在再次打开选择器时不得重复加入；
4. 既有 demand-workbench-browser.mjs、first-use-full-chain-browser.mjs、browser.mjs 正常回归；
5. Vue TypeScript严格检查及Git差异检查通过。

注意：这一操作仅编辑本次需求草稿的临时选择，不自动创建需求、批准、费用或其他正式业务事实。
