## 页面及课程定位
- 工作台（dashboard）：5步短导览；集中查看待办、进度、预警和资金概况。
- 专业需求（demands）：5步短导览；先记录现场问题、作业位置和工作量，再由有权人员确认与项目承接。
- 子项目管理（projects）：5步短导览；管理需求承接、入库、正式批准与变更、费用结项和全部历史。
- 年度框架（frameworks）：5步短导览；统筹年度额度和下属协议、项目预算执行情况。
- 执行协议（agreements）：5步短导览；维护归属年度框架、额度、期限及关联子项目。
- 费用与结算（finance）：5步短导览；以子项目为主线办理真实费用、独立结算单和费用核对。
- 输电设备台账（ledger）：5步短导览；维护线路、物理杆塔、逻辑杆塔和档距等真实设备身份。
- 物资管理（materials）：5步短导览；维护物资名称、型号、规格、计量单位及采用版本。
- 作业标准（standards）：5步短导览；配置作业对象、操作类型、固定计量单位和统一附加属性。
- 参考价格（pricing）：5步短导览；用适用条件、计价方式和正式采用属性试算参考报价。
- 基础数据（dictionaries）：5步短导览；管理计量单位、电压等级、杆塔性质、杆塔材质、组织、类别和优先级等基础事实。
- 系统管理（system）：5步短导览；维护账号权限、IP访问限制和操作审计。
- L01 基础配置：配置单位、组织、字典及作业对象；服务端检查点：有效计量单位拥有明确的正式数量精度
- L02 设备与物资：建立设备身份和物资主数据；服务端检查点：真实线路、杆塔、档距和物资存在合法关联
- L03 作业和计价：配置操作版本、附加属性与参考价格；服务端检查点：正式操作版本和有效价格规则可用
- L04 专业需求：创建并修订多位置需求；服务端检查点：需求正式版本固定操作、设备和准确数量
- L05 确认需求：由审核人员确认需求正式有效；服务端检查点：需求状态有效、事件序号及正式历史正确
- L06 年度框架与承接：建立框架、协议、子项目及单一需求承接；服务端检查点：执行协议归属框架，需求唯一当前子项目
- L07 批准与正式变更：入库、部分范围批准及后续变更；服务端检查点：存在经有权人员审核的正式批准版本
- L08 真实费用：核定费用归属、科目和实际金额；服务端检查点：正式费用记录与项目、科目正确关联
- L09 多次部分结算：进行至少两次独立结算并审核；服务端检查点：存在两份不同身份的正式已批准结算
- L10 费用核对与结项：正式核对差异并结项；服务端检查点：正式核对和项目结项历史可追溯
- L11 Excel批量纠错：模板下载、问题定位、原子或部分提交和回查；服务端检查点：预检不产生写入，合法结果可通过正式编号回查
- L12 权限与正式审计：查看权限和业务历史，验证越权拦截；服务端检查点：服务端403与正式业务审计链均得到核验
