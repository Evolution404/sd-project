### 高风险：上游 ROOT 并不满足权限可编辑裁决

- src/utils/permission.ts 的 hasPerm() 直接使用 roles.includes(ROLE_ROOT) 放行，或 perms.includes('*:*:*') 放行；如果原样使用，管理员一旦去掉部分权限仍会继续看到/执行被撤销的动作（即使业务后端保护正确，也形成严重前端误导）。
- src/views/system/role/index.vue 使用 row.code !== ROLE_ROOT 条件隐藏角色编辑动作。**必须仅移除这些固化角色特权的适配分支，保留原生 UI 布局与组件**，确保“系统管理员默认全部、后续可以编辑”可实测；后端彻底使用有效角色-动作-范围权限，而不是角色字符串 admin 即全权。
- Permission Store 提供 refreshPermissions/reloadRoutes，适合权限修改后更新菜单和标签，但要结合会话失效和安全资源访问测试，不依赖前端刷新保障授权。
- 另查得 src/composables/useRealtime.ts 的 hasPresencePermission() 同样包含 ROOT 和用户 *:*:* 快捷放行；以及官方角色管理页以 ROOT 特判隐藏编辑按钮，迁移时一起取消这两处不能编辑管理员权限的旁路。组件自己声明 *:*:* 作为无需权限的公开按钮可以单独保留，但不能作为用户拥有全部权限的通配授权。

### 高风险：原生多标签和缓存

- src/stores/tags-view.ts 用 fullPath 区分访问和 cachedViews；src/layouts/components/LayoutTagsView.vue 提供关闭标签、刷新、关闭全部等功能。
- 本系统专业需求、项目批准、结算等有未保存草稿；对关闭单一、关闭其它、关闭全部、刷新、浏览器返回必须统一草稿拦截，不得绕过原正式办理离开保护。不同项目 ID 与 query 的缓存必须不串数据；退出后清除所有用户特定缓存。

## C. 暂不引入、避免徒增技术债

- 租户及 TenantSwitcher：当前是单一内网业务实例，多租户没有已确认业务需求。
- workflow/BPMN 工作流引擎：本系统已有不可变正式批准与顺序审核，不得仅为模板控件引入第二套审批状态；需要时仅评估只读可视化。
- codegen/动态表单设计器：短期不取代统一属性定义及服务端校验；若使用需先完成 API/模板契约测试。
- 上游 QR/OIDC/手机验证码登录与 WebSocket/NoticeCenter 实时通知：本系统是 Cookie 会话/内网离线部署，不追加网络依赖；未来明确业务需求后再选。
- VXE Table 完整编辑引擎：本系统已授权 Tabulator 6.x 为专业网格；普通查看走 CrudTable，复杂编辑走 Tabulator，避免双编辑器粘贴/撤销/排序的状态冲突。
- WangEditor、CodeMirror、富文本等：无对应真实业务时不纳入运行包，先排查依赖树与 Windows 离线体积。
- 国际化：当前面向中文业务；保留有来 vue-i18n 框架能力但初期只维护完整中文资源，不生造多语种业务描述。

## D. 上游版本/工程兼容性待实测

上游 package.json：vue-router ^5.2.0、Vite ~8.2.4、Pinia ^4.0.2、Node engine ^24.0.0、pnpm 10.34.5；现役旧项目还是 Node26/Router4/npm。**用户已经决定使用有来原版运行环境：新系统固定 Node24.x、pnpm10、Router5、Vite8 等上游栈；后端与 Windows 运行时也统一迁移至 Node24。** 在隔离环境先运行原版 build 与浏览器，再逐项验证 SQLite、Excel、备份、离线生产依赖、Windows 24.x runtime、正式/演示 ZIP；仅在新栈完整可验证后才替换旧 Node26 脚本和旧 lockfile，未经实际测试不得宣称已切换。

服务端是同源 HttpOnly Cookie，不使用上游 accessToken/refreshToken；允许改用户 Store/axios 拦截器与登录 API，但必须保留同源会话、CSRF/Origin、防重、冲突和日志。上游纯角色 ROOT 特权必须清除。

上游原版 4.13.0 的 src/views/dashboard/index.vue 包含多个通向开源文档的链接；这些不是输电系统业务内容，可以替换成项目真实快捷入口，**保留 UI 结构**而不保留无关业务文案。

## E. 按阶段落地与防假复用验收

每个上游源码条目须保存：上游相对路径、SHA、当前运行代码路径、直接引用证据、适配 diff、功能测试、同尺寸截图。仅复制进 docs/vendor 不算复用。源 UI 不一致即验收不通过，不能以路由可访问或组件 build 通过作为“界面完成”。
