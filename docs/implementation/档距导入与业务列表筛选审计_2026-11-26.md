# 档距导入与业务列表筛选审计

## 档距方向

真实台账导入时已按来源编号规则为同线路杆塔生成顺序。导入档距以前直接保存源端点方向。导入器现在对同线路端点沿用已生成的杆塔顺序。跨线路、身份不清或顺序有歧义的档距由专用拓扑流程处理。

维修脚本对已有导入目录采用独占锁、独立备份、已有管理员鉴权及目录事务。通过设备服务交换明显反向的首版记录端点，追加正式档距版本和审计。保留档距身份、线路、管辖长度、状态及旧版本。正式数据使用原始导入回执验证稳定身份。作业位置和正式快照依旧绑定原业务身份。维护记录和备份仅存本机受控目录。

## 正式页面的筛选口径

| 页面 | 查询方式 |
| --- | --- |
| 输电线路 | 名称或编号、电压等级、线路性质，表头保留状态筛选。电压采用字典身份精确匹配。 |
| 物理杆塔 | 编号、铭牌及现有关键词，补关联线路与杆塔材质。 |
| 逻辑杆塔 | 杆号及现有关键词，补线路、电压、运维班组、管理部门。 |
| 档距 | 所属线路、电压、分开的起止杆号，以及可单侧或双侧填写的管辖长度范围。以米录入、按整数毫米在数据库比较。边界包含端点，有范围条件时未知长度排除。 |
| 电压等级、计量单位及其他字典 | 保留名称与状态，计量单位补数量精度。有层级的组织目录保留树搜索，增加状态。 |
| 专业需求 | 需求状态、编号及描述等原查询，补作业线路、操作类型、承接项目与预计解决日期。线路按需求保存的作业位置快照查找。 |
| 子项目与按项目办理财务 | 项目编号、名称及六态，补年度框架、协议、类别、归口单位及计划开工日期。财务项目入口补框架及归口单位。 |
| 年度框架与执行协议 | 精确匹配年度，协议同时支持框架、签约对方、合同号及截止日期范围。 |
| 实际费用、费用核对与结算 | 保留事项、账单及状态，在适用视图提供费用科目、所属项目、结算编号及业务日期。 |
| 物资 | 编码、名称及状态，支持型号、规格、单位独立组合筛选。 |
| 作业标准及参考价格 | 作业对象按位置和归属单元，操作类型按采用对象和单位，参考价格按操作、电压、计价模型、来源及生效日期。 |
| 用户、角色与 IP 授权 | 用户按状态、角色和关联组织。角色按名称或编码及状态分页。IP 地址和用途可组合查询。 |
| 审计与访问日志 | 审计按北京时间日期、操作账号、事件或业务对象补充筛选。现有访问日志保留北京时间、账号、IP、状态码及方法。 |

查询继续使用原生 CrudSearch、列筛选和 Element Plus，业务条件参与同一服务端分页查询。表单、办理页和仪表盘沿用其所依赖的业务范围。
