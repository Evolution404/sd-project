## 使用指引纠正与实操复验

先前仅打开和关闭了指引。原浏览器用例也只走到导览首卡，随后按 Escape 退出。用户报告后，通过 Computer Use 复现了点击「下一步」停留在首卡，以及工作台「查看待办」因为重复定位标记而无法打开说明。

- 导览步序双向绑定，等待指引抽屉退出后才展示导览卡片。点「下一步」「上一步」均能改变内容，走完五步可以结束并立即重新打开指引。360 像素视口中卡片实测位于第 12至348 像素，按钮完整可用。
- 工作台待办理区域使用唯一定位标记。按实际业务条件打开可定位的界面，对含有多条记录的共用按钮给出明确提示，由用户选定对象。搜索结果显示中文模块名。
- 模块和课程提供显式业务页入口。Computer Use 实测从搜索进入专业需求、带未保存需求草稿时尝试跳转并保留原内容、完整阅读结算课程并从课程进入财务页面。课程可续读，完成后从第一步重学。
- 立项课程及操作说明更新为整条需求承接。结算课程和说明明确总额、子费用两种方式与独立选填的解决量。普通演示实例的课程阅读和独立训练实操分别显示，指引阶段的浏览器回归核对零业务写入。

## 长列表与叠加弹层复验

专业需求演示列表 24 条记录。在 1512 × 866 窗口中进入第四步「查询、筛选与查看」，原实现定位整块列表，说明卡片顶部被推到第 1053 像素，遮罩仍覆盖页面。从需求详情打开指引时还复现了另一种阻断。导览在应用初次加载时取得的弹层顺序低于后来打开的需求详情抽屉。

- 导览卡片固定在当前窗口内，长列表定位表头。每次启动导览时，在说明抽屉收起后取得最新的弹层顺序，使卡片和遮罩显示在当前业务详情或弹窗上方。
- 最终版通过 Computer Use 逐一打开工作台、专业需求、子项目管理、年度框架、执行协议、费用与结算、输电设备台账、物资管理、作业标准、参考价格、基础数据和系统管理。在 1512 × 866 和 360 × 800 两种窗口各走完全部五步，共 120 步。逐步检查按钮位于窗口内且能收到点击，实际执行下一步、回退和结束，并检查结束后的页面入口恢复。
- 在专业需求 24 条记录的完整列表确认第四步能继续，并验证关闭按钮和 Escape 均可退出。需求详情和 Excel 数据交换弹窗内各走完五步，Excel 模板定位也能结束并回到原弹窗。验收打开和展开说明，未确认业务写入。
- 十二门课程 L01 至 L12 均通过可见「下一步」读完四步，逐一核对「已阅读」。课程实操状态仍以独立训练实例的业务记录为准。
- 两项指引浏览器回归通过。长表格回归采用有演示数据的隔离数据库，检查实际命中区域及退出后的筛选。详情及 Excel 回归点击导览控件后确认原弹层仍可用，同时检查零业务写入。
