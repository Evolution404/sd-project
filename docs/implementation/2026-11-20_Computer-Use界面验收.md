## 使用指引纠正与实操复验

先前仅打开和关闭了指引。原浏览器用例也只走到导览首卡，随后按 Escape 退出。用户报告后，通过 Computer Use 复现了点击「下一步」停留在首卡，以及工作台「查看待办」因为重复定位标记而无法打开说明。

- 导览步序双向绑定，等待指引抽屉退出后才展示导览卡片。点「下一步」「上一步」均能改变内容，走完五步可以结束并立即重新打开指引。360 像素视口中卡片实测位于第 12至348 像素，按钮完整可用。
- 工作台待办理区域使用唯一定位标记。按实际业务条件打开可定位的界面，对含有多条记录的共用按钮给出明确提示，由用户选定对象。搜索结果显示中文模块名。
- 模块和课程提供显式业务页入口。Computer Use 实测从搜索进入专业需求、带未保存需求草稿时尝试跳转并保留原内容、完整阅读结算课程并从课程进入财务页面。课程可续读，完成后从第一步重学。
- 立项课程及操作说明更新为整条需求承接。结算课程和说明明确总额、子费用两种方式与独立选填的解决量。普通演示实例的课程阅读和独立训练实操分别显示，指引阶段的浏览器回归核对零业务写入。
