# 有来 UI 公共组件治理与业务配置规范（2026-11-24）

## 范围与约束
基线：814ff1e；审计证据位于 .build/ui-audit-20261124/。本轮遵循原版 vue3-element-admin 4.13.0：普通查询使用 CrudPage/CrudSearch/CrudTable/CrudForm 和 Element Plus 原生组件；只通过公共组件现有扩展点、业务列配置、原生布局属性和服务端查询完成适配。禁止新增第二套 CRUD、表头/筛选菜单、伪分页或逐页复制样式；Tabulator 仅用于明确的工作表/批量编辑态，不替代普通列表。

## 公共组件规范
1. 普通列表使用单一有限高度容器、原生内部表格滚动及分页，搜索区/工具栏/分页不随表格内容无限增长。嵌套页签使用嵌入式 CrudPage，不重复满高及内边距。
2. 搜索控件通过原生宽度属性及有来网格布局保持空态和已选态可读；允许业务配置覆盖。
3. sortable:'custom' 使用 Element Plus 真实表头箭头；仅对后端白名单允许的列启用，不使用当前页本地排序冒充全局排序。原生 filters/columnKey 对接服务端 grid_filters；状态候选使用领域稳定值和中文标签，清除后恢复全量；同一字段表头和搜索条件取交集。排序清除恢复默认 created_at desc。排序、筛选先于分页，导出沿用成功查询快照，不得导出另一组条件。
4. 业务列表接口只接受显式允许的列和筛选字段；保留固定点位 ID、金额精度及权限条件。业务页面显示项目、设备及物资名称/编号，不以 UUID 作为正常用户主标识。时间显示统一既有北京时间工具。
5. 固定列、分页、深色主题、对话框使用原生组件规则。对于原主题已经存在的透明悬浮背景等兼容缺陷，公共层最小修正，不自行重画主题。批量编辑采用明确进入/退出、保存/取消、跨页或已选范围和离开保护。
6. 路由截图验收须断言目标路由与独有内容、接口返回、加载结束及动画结束，不能只等待通用表格。以有数据的正式生产构建、四种宽度、双主题及关键弹窗作为证据。至少验证第二页排序/筛选、清除、查询总数、越权、导出一致性及实际键盘操作。
7. 权限组显示必须根据真实子权限计算三态，不能保存展示用虚拟父级为授权事实。
