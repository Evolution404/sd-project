# 统一业务工作表规范（2026-11-24，W0）

基线 34e3484。正式前端保持有来原版 CrudTable/CrudPage、Element Plus；用户已批准将 Univer Sheets 1.6.1 扩展为唯一专业编辑引擎。展示、选择、批量修改、单据录入四类交互；前两类不得加载编辑引擎。物资和设备主动进入独立编辑页，未选择时当前页、已选择时选中范围，最多100条；单据编制直接录入完整业务范围。不可静默截断。所有复杂业务引用由原生表格选择器维护。

## 契约
稳定行 ID、列 key、不可变原始快照、原始文本草稿、唯一操作历史、校验输出。编辑引擎只负责交互，不导入业务 API，不保存 workbook JSON，不改变 Schema113。业务适配器决定行权限、冻结版本、精度、校验和请求映射。单据所有工作表先结束编辑再联合校验；只提交正式业务命令。台账批量修改按字段白名单和逐行版本检查原子执行，不循环单条请求。
最新裁决：粘贴、清除和拖填的目标包含任何只读单元格时整次拒绝，不部分写入；允许 Univer 原生权限提示。越界整次拒绝。优先复用原生剪贴板、权限及撤销重做；禁止并行自定义快捷键、跳过只读格、拆分写入区块或屏蔽原生报错。无效数据保留并集中标红拦截保存。公式作为文本。一次粘贴/填充对应一次撤销；多实例键盘焦点隔离，错误定位恢复输入焦点。主题、滚轮、加载、未保存离页与原生浮层遵守系统开发规范。
## 初始化与字段独立性门禁
工作表在 Univer Rendered 生命周期、画布帧及原生权限范围就绪后开放编辑；不得等待固定延时的 Steady 阶段。提前获取原生 AutoFillUIController 单例，保留后续正常生命周期与原生拖填。20行8列实测首次3706ms降至729ms，再次3389ms降至405ms；回归检测就绪耗时小于1500ms、再次打开总耗时小于1800ms。严格按 AGENTS.md 独立列裁决处理所有业务字段，历史快照只投影、不得覆写；check:field-independence 纳入统一 check 门禁。
## 工作包与门禁
执行顺序 W0→W1→W2→W4→W3→W5→W6→W7→W8。W1 真实结算无损回归；W2 公共编辑边界及生命周期；W4 物资真实原子保存；W3 需求位置、物资、动态属性；W5 批准物资和子费用；W6 领域批量命令及拓扑保护；W7 正式前端零 Tabulator、保留隔离历史夹具；W8 工程/Schema/性能/正式及历史浏览器/P10/Windows双包门禁。各包单独记录实测结果；不得将未执行测试标为通过。1920×1080、100%缩放及明暗主题真实截图，Windows宿主包验证与实机运行分别记录。性能以基线实测为准，不凭空承诺。

## B0–B9 增强规则
枚举在正式界面和 Excel 采用中文显示，传输使用稳定业务值。Univer 1.6.1 官方数据验证、筛选、排序扩展与核心同版本。下拉由业务定义提供，Excel 采用隐藏字典和命名范围；主支线转换、归属关系、计量单位身份不开放普通批改。排序是整行视图操作，保持行 ID。旧实现存在编辑历史时要求先保存或取消，R1 必须消除该限制且保留草稿及统一历史；筛选不改数据，隐藏行仍参加保存与校验，跨隐藏行粘贴和拖填拒绝。列表以独立线路数、详情明细取代聚合字段；兼容历史夹具保留旧查询投影。

## R1 工作表历史与业务身份

当前草稿决定整行视图排序。排序和筛选保留原工作簿与筛选条件，不产生一笔业务撤销。原生编辑时把可写文本的前后值绑定到稳定行 ID，剪贴板和填充由 Univer 作为一次命令记录。业务增删同样进入 `IUndoRedoService`，键盘、撤销按钮和重做按钮使用同一历史。可移除选区跳过筛选隐藏和锁定行，业务父表单接收完整结构变动，并将数据按原业务顺序和身份提交。已载入另一单据或正式定义时才建立新会话。
