# Schema 113｜触发器与约束责任全量审计

与当前权威 SQL 核对：触发器负责对象关系/正式版本/真实身份/逐位置数量核对、完整价格事实及已确认历史的不可变边界。尤其在立项批准时重新核对已选正式报价是否仍与批准逐位置数量一致。参考价匹配、阶梯金额计算、项目总参考金额汇总和管理员角色授权仍严格属于应用层，不在 SQLite 编写业务算法。
